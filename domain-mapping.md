- **`rel-bulk-endpoint-no-pagination`** — pool `location_template` resolves to `services/invoice-review-service/.../controller/ContractModificationController.java`. - **`rel-bulk-endpoint-no-pagination`** — pool `locked_failing_test` proposes a live HTTP probe (seed 2000 rows, GET endpoint, assert 400-or-paginated). Adapted to a unit-style test that exercises the controller method directly with a Mockito repo stub. Same invariant (size <= 100), lighter infra. Noted in test docstring.
- **`obs-metric-unbounded-cardinality`** — pool location resolves to a `metrics/{AspectEntity}Metrics.java` path that does not exist in baseline. Created fresh (effectively `inject_mode: create_new`) under `invoice-review-service` (the review-half service per the pool template). Depends on `MeterRegistry` from micrometer-core (transitively present via `spring-boot-starter-actuator`).
- **`obs-healthcheck-always-200`** — pool location resolves to a `controller/HealthController.java` path that does not exist in baseline (Spring Boot Actuator handles `/actuator/health` by default in acquire-gov). Created fresh as a dedicated `@RequestMapping("/health")` controller that k8s deployments + GHA smoke-test scripts point at — the production-path bug. Cohort decides whether to delete this controller and route k8s at `/actuator/health`, or fix the controller in place.
- **`ai-prompt-template-user-controlled`** — pool `bug_sketch` references "Draft a {aspect_entity}" where `aspect_entity` resolves to `contract-modification` (kebab form). Kept the kebab token in the user-visible prompt body for fidelity to the template; the bug surface is the f-string interpolation pattern, not the noun choice. Test invokes a stub `draft` fn (no live Bedrock) that mimics the canonical injection failure mode — fixed implementation would refuse to echo "HACKED" because input would be sanitized + wrapped in `<user_request>` tags.

two classes named `ContractModification` when grepping. This is **intentional richness**

delete the legacy one in `invoice-review-service` since it duplicates intent, or rename
